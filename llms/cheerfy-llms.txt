# Cheerfy

> Cheerfy is a customer-engagement and digital-experience platform for restaurants and hospitality
> brands, combining CRM and loyalty, online ordering, pay-at-table, self-service kiosks and a
> multi-brand marketplace. It centralizes customer data from POS, bookings, Wi-Fi and payment
> systems, then drives automated SMS, email and push marketing, branded loyalty cards, wallet-ready
> digital coupons, feedback surveys and real-time analytics. Cheerfy documents a Loyalty Card API
> and a Coupons API for point-of-sale integration.

Generated by the API Evangelist enrichment pipeline on 2026-08-10 from apis.yml and the artifacts in
this repository. Cheerfy does not publish an llms.txt of its own — https://docs.cheerfy.com/llms.txt
returns a 307 redirect into the GitBook application shell.

## Status of the machine-readable contract

- No OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema is published at any Cheerfy
  location. Probed: cheerfy.com, www.en.cheerfy.com, docs.cheerfy.com, api.cheerfy.com,
  webhook.cheerfy.com, auth.cheerfy.com and admin.cheerfy.com.
- The API reference pages at docs.cheerfy.com 307-redirect to app.gitbook.com and render only a
  JavaScript shell, so the documented endpoints are not readable by a machine.
- api.cheerfy.com resolves but returns HTTP 503 on every path — the load balancer behind it has no
  rule for that hostname.
- The one reachable API host, webhook.cheerfy.com, challenges with `WWW-Authenticate: Token` and
  returns `{"detail": "..."}` error bodies (Django REST Framework).

## APIs

- [Loyalty Card API (API Tarjeta de Fidelización)](https://docs.cheerfy.com/es/cheerfy-loyalty/api-tarjeta-de-fidelizacion): Loyalty card integration for point-of-sale systems. Reference is JavaScript-rendered.
- [Coupons API (API Cupones)](https://docs.cheerfy.com/es/cheerfy-loyalty/api-cupones): Coupon redemption from a point-of-sale system. Reference is JavaScript-rendered.
